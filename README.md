# Ancandi GitHub Pages

This repository is a Jekyll site ready for GitHub Pages.

Last redeploy trigger: 2026-05-07 23:14 Asia/Taipei.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then open `http://localhost:4000`.

## Structure

- `_config.yml` configures GitHub Pages, SEO, feed, and sitemap plugins.
- `_layouts/default.html` is the shared page shell.
- `_includes/` holds the head, header, and footer partials.
- `assets/css/styles.css` contains the fluid responsive styling.
- `assets/js/main.js` adds small interaction enhancements.
